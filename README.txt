Название проекта: Rick and Morty — каталог персонажей
API: https://rickandmortyapi.com/api/character

Описание:
Небольшой сайт на Django, который получает список персонажей из открытого
Rick and Morty API (GET-запрос, JSON) и выводит их карточками на главной
странице. Для каждого персонажа показаны фото, имя, статус, вид, пол,
происхождение, последняя известная локация и количество эпизодов.

Структура работы:
- views.py: requests.get() -> response.json() -> контекст шаблона;
- index.html: вывод карточек через цикл {% for %};
- оформление: CSS внутри <style> (тёмный фон, сетка, рамки и подсветка карточек).

Запуск:
1. Создайте виртуальное окружение:
   python -m venv venv
2. Активируйте его:
   Windows: venv\Scripts\activate
   macOS/Linux: source venv/bin/activate
3. Установите зависимости:
   pip install -r requirements.txt
4. Запустите сервер:
   python manage.py runserver
5. Откройте в браузере:
   http://127.0.0.1:8000/

Примечание: для работы сайта нужен доступ в интернет, потому что данные
загружаются из API во время выполнения запроса.
